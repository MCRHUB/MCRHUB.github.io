MTL领域概述

MTL（Market to Lead）是企业营销体系的前端引擎，核心在于通过系统化的市场洞察、精准的客户细分与多维度的触达策略，将广泛的市场机会转化为可跟进、可培育的销售线索。它并非简单的广告投放或活动执行，而是一套覆盖市场调研、品牌传播、内容营销、数字投放、活动运营与线索评分机制的完整闭环。MTL强调以客户画像和购买旅程为基础，在不同触点传递一致且有价值的信息，从而激发潜在客户的兴趣与互动。通过市场线索打分、行为追踪与自动化培育，市场部门能够持续输出高质量、高意向的线索，为后续销售转化奠定坚实基础。简言之，MTL解决的是“让对的人在对的时间遇见对的产品”这一根本问题，是打通市场与销售协同的第一道关口。

三、常见术语

1、总市场空间（TAM，Total available market ）

理论上某个产品或服务可以覆盖的整个市场需求总量。

2、可参与市场空间（SAM，Serviceable Available Market）

SAM 是 TAM 的一部分，即企业基于其现有核心能力和过往业绩实际能够触达和覆盖的那部分市场的空间。

3、目标市场空间（TM，Target Market Space ）

TM 是 SAM 的一部分，目标市场空间是指一个产品或服务在特定市场中潜在的可销售量或收入规模，它反映了市场对该产品或服务的需求潜力。

4、客户心理历程（AIDA 模型）

客户心理历程是指客户从认识到需要某种产品或服务，到最终购买并使用该产品服务的整个过程中的心理变化和行为轨迹。这一过程包括了客户对产品或服务的认知、兴趣、渴望、行动等阶段。

5、市场细分和细分市场

市场细分，就是营销者通过市场调研，依据客户的需要与欲望、购买行为和购买习惯等方面的明显差异性，把某一整体市场划分为若干个客户群体的市场分类过程。在这里，每一个客户群就是一个细分市场，细分市场就是有相同或类似需求的客户组合。

6、市场细分框架

根据业务需要，通过整合大量第三方数据并分析和建模，从多个维度描述细分市场；将一个大而同质化的市场，分为清晰的、可识别的、拥有相同或类似需求的各个细分市场。标杆公司市场细分框架如下图所示：

7、细分市场营销计划（MSP，Marketing Segment Plan）

对齐业务目标，规划营销活动和上市计划，根据业绩表现，定期刷新上市计划，并推动落实。细分市场营销计划主要包括：细分市场业务目标、市场分析、营销策略、季度上市计划以及相关考核指标等。

8、价值主张

价值主张是指公司的产品和解决方案针对特定销售机会所产生独特价值。价值主张中“价值”不是指你交付什么，而你的客户可以获得什么。价值主张清晰定义了你的产品或服务为客户带来的、区别于竞争对手的独特价值。价值主张是营销活动的源头。

9、信息屋（KMH，Key Message House）

高度提炼和总结的营销传播内容，涵盖支撑愿景和目标的关键信息，形成闭环商业逻辑的营销信息族，包含的信息如下图所示：

10、品牌精粹

最重要的品牌组件，包括：定位、价值承诺和竞争优势。我们从行业发展角度所提出的对世界的前瞻性理念，该理念将在未来较长时间被客户、行业及相关人共同关注并探讨。可作为公司内外部沟通的核心主题。

11、价值主题

在特定时期内，向客户承诺的“未来能力”与“交付价值”的集中表达。它不是简单的产品功能列表，而是站在客户视角，回答“为了在未来竞争中获胜，客户必须具备什么能力，而我们能提供什么承诺”这一根本问题。它是连接公司战略愿景与具体营销、交付动作的“定海神针”，通常保持 3-5 年的稳定性，确保我们在不同阶段、不同场景下“说同一种语言，做同一件事”。

12、营销要素

营销要素是指在营销活动中所涉及的各种关键因素，包括产品、价格、渠道和促销等，它们共同作用以实现营销目标。

13、营销活动（Tactic）

为达成某一特定目的而设计的单一市场营销活动，包括展会，峰会，研讨会，直邮，网站等。

14、交付物（Offer）

是指在营销推广过程中，引起客户响应的资料或行为活动，比如白皮书、Demo 演示、视频、机场广告等。同一个 Offer 可以被不同的 Tactic 调用。

15、营销活动组合（Campaign）

规划并执行系列营销活动 Tactics 组合，在特定时期向特定的目标客户、利用多种营销活动持续传递一系列的信息，实现营销目标。

16、营销方案（Program）

针对特定的客户 ( 含潜在客户 ) 群制定的产品及解决方案的营销方案。它包含一个或多个营销 Campaign，需要确保关键信息传递的一致性和关联性。

17、营销框架（MPF，Marketing Program Framework）

为公司所有的事业部或产品线、所有的区域指明营销工作的方向，是经过批准的一组Program 的集合。

18、整合营销传播（IMC，Integrated Marketing Communications）

整合营销传播（IMC）是在一个公司内协调和整合所有的营销传播内容、工具、途径，形成一个无缝的方案，以最小的成本，对消费者和其他最终用户产生最大化的影响。

19、响应（Response）

受众对和营销活动（Tactic）相关的某个交付物（Offer）的反馈，如看到某个视频广告后通过线上线下等方式咨询相关信息（如价格、产品配置、销售方式等），这种咨询行为被统称为受众的响应。响应通常包含该受众的有效联系信息，有利于后续保持联系，产生线索。

20、销售通路

指一种常规的销售渠道或路径结构，市场细分确定后一般需要确定产品 / 解决方案的如何上市（Go To Market），其中一个重要任务就是要确定它们的销售通路，本质上它要解决如何通过各级经销商、销售门店把产品 / 解决方案销售给最终用户的路径问题

1、常见业务分析模型

1.1、麦肯锡九宫格

基本信息：

全称GE-McKinsey 九格矩阵，俗称麦肯锡九宫格，1970 年代麦肯锡为通用电气（GE）打造的业务组合 / 市场投资分析工具，用来弥补 BCG 矩阵（仅市场增速 + 市占率两个单一指标）过于简单的缺陷。

核心用途：

对集团多条业务线、产品线、细分市场做标准化评估，判断资源该加码、维持还是撤出，是市场战略、资源分配最经典框架之一。

核心定义：

GE麦肯锡九宫格标准图核心逻辑（双维度 3×3 九宫格）

纵轴 Y：行业吸引力（外部市场环境），分「高 / 中 / 低」

横轴 X：业务竞争实力（企业自身优势），分「强 / 中 / 弱」 两两组合形成 9 个格子，每个格子对应一套市场战略。

各维度详细解析

两大评估维度（市场分析核心打分指标）

1. 纵轴：行业吸引力（看市场好不好）多指标加权打分，衡量赛道长期盈利潜力：市场规模、年增长率、行业平均利润率竞争激烈程度、进入 / 退出壁垒政策监管、技术迭代空间、周期性、上下游议价能力 得分越高 = 赛道越优质，值得布局。

2. 横轴：业务竞争实力（看你在市场强不强）评估自身在该赛道的相对优势：市场份额、品牌影响力、渠道覆盖成本优势、研发 / 产品力、毛利率、客户粘性管理团队、供应链、专利壁垒 得分越高 = 企业在该市场话语权越强。

9 个格子分区 + 市场战略（分三大区域）

第一区：优先投资增长区（右上角 3 格，绿色）高吸引力 + 强实力（右上最优） 市场前景好、自身龙头地位战略：全力加码、扩产能、加大营销研发、并购抢占份额，核心现金牛增长业务。高吸引力 + 中等实力（右中） 赛道优质，但竞争力一般战略：重点补强短板（渠道 / 产品），选择性大额投入，追赶头部。中等吸引力 + 强实力（中上） 市场增速一般，但企业垄断地位战略：守住份额、优化盈利，适度投资提升现金流。

第二区：选择性维持 / 谨慎投入（对角线 3 格，黄色）高吸引力 + 弱实力（左上） 赛道很好，但企业无竞争力战略：不单独硬投，寻求合资、收购竞品；无合作机会则放弃该细分市场。中等吸引力 + 中等实力（正中） 市场平平、自身不上不下战略：选择性投入，砍掉低效产品线，只保留高毛利细分，不扩张。低吸引力 + 强实力（右下） 赛道萎缩，但你是行业龙头战略：收割现金流，少新增投入，择机高价出售业务。

第三区：收缩收割 / 退出区（左下角 3 格，红色）中等吸引力 + 弱实力（左中） 市场一般、自身无优势战略：缩减预算，只维持基础运营，逐步收缩市场范围。低吸引力 + 中等实力（中下） 行业下行，竞争力普通战略：榨取短期现金，停止一切新增投资。低吸引力 + 弱实力（左下最差） 赛道衰退 + 企业毫无优势战略：快速剥离、关停、出售业务，及时撤出该市场。

和 BCG 矩阵（波士顿矩阵）核心区别（市场分析对比）

市场分析典型应用场景

  1. 集团多业务赛道评估：判断旗下各板块市场优先级，分配年度营销、研发预算；

  2. 多产品线优化：快消 / 电子企业评估各产品细分市场表现，淘汰弱势 SKU；

  3. 新市场拓展决策：评估待进入细分赛道吸引力 + 自身匹配度，决定是否入局；

  4. 并购 / 资产剥离研判：判断标的业务所处九宫格位置，测算投资回报；

  5. 年度战略复盘：统一管理层对各市场的判断，避免资源平均主义。

实操落地步骤（市场分析标准流程）

  1. 拆分所有业务 / 细分市场单元；

  2. 分别制定「行业吸引力」「竞争实力」打分表，设置指标权重；

  3. 收集行业数据、企业经营数据，逐项打分并加权算出总分；

  4. 将每个业务单元标注在九宫格内（可用气泡图，气泡大小代表营收规模）；

  5. 按格子分区制定对应市场策略，重新分配公司资源。

补充区分：两中“九宫格”不要混淆

  1. GE - 麦肯锡业务九宫格：市场 / 业务战略分析，维度 = 行业吸引力 + 竞争力；

  2. 人才九格矩阵：人力资源工具，维度 = 员工绩效 + 潜力，和市场分析无关。
